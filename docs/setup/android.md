# Android setup

**Android 11 or later (wireless debugging)**
1. **Settings → About phone**, tap **Build number** seven times.
2. **Settings → Developer options → Wireless debugging: On.**
3. Tap **Pair device with pairing code**: note the IP:port and six-digit code.
4. In Tether choose **Add device**, pair with that code, then connect to the IP and port on the main Wireless debugging screen.

**Android TV / Google TV:** Settings → System → About → click Build seven times, then Developer options → USB debugging
(and Wireless debugging if offered); connect by IP and approve the prompt on the TV.
