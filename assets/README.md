# Tether icon

`icon.png` is the full-resolution transparent master, generated with the built-in imagegen tool.
`AppIcon.icns` contains the standard and Retina Mac sizes; `docs/images/logo.png` is the README rendition.
Rebuild both with `./scripts/make-icon.sh` (Swift and macOS `sips` are required).

Design prompt: a native macOS icon on a midnight navy rounded-square tile, with two broad ice-silver and electric-blue
interlocking cable links forming an abstract T. Satin ceramic/metal, shallow bevels, restrained highlights, front view,
generous negative space for legibility at Dock sizes; transparent outside the tile, no lettering or badges.
